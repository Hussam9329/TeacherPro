# إضافة «إغلاق كود مرماز»

زر الخطر ☢️ بكارت الطالب في «اغلاق الكودات» يفتح صفحة الطلاب بمرماز. هذه الإضافة تكمل الشغل هناك:

1. تبحث برقم هاتف الطالب بجدول الطلاب (كل السنوات، الفعّال والمغلق).
2. تعرض اللي لكته: الاسم، والدورة، والرقم، والحالة.
3. بعد ما تضغط **«تأكيد إغلاق الكود»** تطفي مفتاح «حالة الدورة للطالب»، نفس المفتاح اللي تطفيه بيدك.
4. تحدّث الجدول من مرماز وتتأكد إن الكود انغلق فعلاً، وإذا ما انغلق تكلك تغلقه بيدك.

ما تغلق أي شي بدون تأكيدك. والطالب ينختار تلقائياً بس إذا رقمه مطابق تماماً.

## التنصيب (مرة وحدة لكل جهاز)

1. افتح Chrome أو Edge واكتب بالعنوان: `chrome://extensions` (أو `edge://extensions`).
2. شغّل **وضع المطوّر (Developer mode)**.
3. اضغط **تحميل إضافة غير مضغوطة (Load unpacked)** واختار هذا المجلد: `extensions/mirmaz-code-closer`.
4. سجّل دخولك لمرماز بنفس المتصفح.

إذا تغيّر ملف الإضافة، اضغط زر التحديث ↻ على الإضافة بنفس الصفحة.

## بدون الإضافة

الزر يشتغل مثل قبل: يفتح مرماز وينسخ رقم الطالب حتى تلصقه بالبحث.

## ملاحظات

- رقم الطالب يوصل للإضافة بنهاية الرابط (`#tp-close=…`). هذا الجزء من الرابط ما ينرسل لسيرفر مرماز، والإضافة تمسحه من شريط العنوان أول ما تقرأه.
- إذا ما كنت مسجّل دخول، الطلب ينتظر 10 دقائق. سجّل دخولك وارجع لصفحة الطلاب وتكمل الإضافة.
- مفتاح مرماز يقلب الحالة بكل ضغطة، فالإضافة ما تضغطه إلا إذا كان الكود فعّال بآخر تحديث للجدول، وما تضغطه مرتين.
